**Модуль 06**

Тема: Защита доступа к API

Цель работы:
Научиться настраивать аутентификацию в ASP.NET Core Web API, создавать JWT-токены и ограничивать доступ к методам API.

## Задание

Создайте ASP.NET Core Web API для работы с данными о товарах (Product).

Модель Product должна содержать:

- Id
- Name
- Price
- Category

Реализуйте следующие API-методы:

- `GET /api/products` - получить список товаров;
- `GET /api/products/{id}` - получить товар по ID;
- `POST /api/products` - добавить новый товар;
- `DELETE /api/products/{id}` - удалить товар.

## Защита API

Настройте JWT-аутентификацию.

Реализуйте отдельный метод входа:

```
POST /api/auth/login
```

Метод должен принимать логин и пароль. При правильных данных сервер должен сформировать и вернуть клиенту JWT-токен.

Настройте JWT с указанием:

- Issuer;
- Audience;
- срока действия токена;
- ключа подписи.

## Авторизация

Используйте атрибут `[Authorize]` для защиты API.

Установите следующие правила:

- просмотр списка товаров доступен без авторизации;
- просмотр одного товара доступен без авторизации;
- добавление товара доступно только с JWT-токеном;
- удаление товара доступно только с JWT-токеном.

Проверьте работу защищённых методов:

**без токена → HTTP 401 Unauthorized**

**с корректным токеном → успешное выполнение запроса**

## Дополнительное задание

Добавьте в JWT Claim с именем пользователя.

Получите значение Claim внутри одного из защищённых методов через `HttpContext.User.Claims`.

## Что необходимо предоставить

Исходный код проекта и скриншоты проверки запросов:

1. Получение JWT-токена.
2. Вызов защищённого API без токена.
3. Вызов API с `Authorization: Bearer <token>`.
4. Успешное добавление товара.
5. Проверка ситуации с неправильным или просроченным токеном.

Важно: секретный ключ JWT не должен передаваться клиентом вместе с каждым запросом. Для обращения к защищённому API клиент использует полученный JWT-токен.
