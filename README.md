# Модуль 06 — защита доступа к API

Тема №6 в [плане курса](../../../docs/uni/web%20services/web%20services%20темы.md)
совпадает с темой трёх оригинальных методичек модуля 06. Отдельного календарного
срока сдачи в этих документах нет.

**Состояние:** решения всех трёх работ есть и проверены автоматически в памяти (без запуска серверов). Скриншотов пока нет — их снимают после своего запуска. Запуск любой работы: `dotnet run` в её папке.

| Работа | Оригинал | Текстовая копия | Что требуется |
|---|---|---|---|
| Домашняя | [docx](Модуль%2006%20Домашнее%20задание.docx) | [Задание](homework/Модуль_06_Домашнее_задание.md), [решение](homework/README.md) — http://localhost:5122 | API товаров `/api/products`, вход `/api/auth/login`, JWT, `[Authorize]` на POST и DELETE, Claim с именем пользователя |
| Лабораторная | [docx](Модуль%2006%20Лабораторная%20работа.docx) | [Задание](lab/Модуль_06_Лабораторная_работа.md), [решение](lab/README.md) — http://localhost:5161/swagger | Task Management API `/api/tasks`, JWT с Claims Name и Role, шесть проверок безопасности |
| Практическая | [docx](Модуль%2006%20Практическая%20работа.docx) | [Задание](prac/Модуль_06_Практическая_работа.md), [решение](prac/README.md) — http://localhost:5162/swagger | API товаров `/api/product`, защита через `X-Api-Key`, затем JWT и Bearer-токен |

Все три методички требуют скриншоты или записанные HTTP-коды проверок; их нужно
снимать после самостоятельного запуска.
