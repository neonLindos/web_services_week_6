Тема: Защита доступа к API

## Цель работы

Получить практические навыки настройки аутентификации и авторизации в ASP.NET Core Web API, создания JWT-токенов и организации доступа к защищённым ресурсам API.

## Задание

Необходимо разработать Web API для управления задачами пользователей - Task Management API.

API должен позволять получать, создавать и удалять задачи. Доступ к части методов необходимо ограничить с помощью JWT-аутентификации.

## 1. Создание проекта

Создайте новый проект: ASP.NET Core Web API

Создайте модель TaskItem со следующими свойствами:

```csharp
public class TaskItem
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Description { get; set; }
    public bool IsCompleted { get; set; }
}
```

Добавьте несколько тестовых записей.

## 2. Реализация API

Создайте TasksController.

Реализуйте следующие методы:

- `GET     /api/tasks`
- `GET     /api/tasks/{id}`
- `POST    /api/tasks`
- `DELETE  /api/tasks/{id}`
- `GET /api/tasks` должен возвращать все задачи.
- `GET /api/tasks/{id}` должен возвращать задачу по её идентификатору.
- `POST /api/tasks` должен добавлять новую задачу.
- `DELETE /api/tasks/{id}` должен удалять задачу.

## 3. Создание системы аутентификации

Создайте отдельный контроллер:

```
AuthController
```

Реализуйте метод:

```
POST /api/auth/login
```

Метод должен принимать логин и пароль пользователя.

Например:

```json
{
    "username": "student",
    "password": "12345"
}
```

Если логин или пароль неправильные, API должен вернуть:

```
401 Unauthorized
```

Если данные правильные - сервер должен сформировать и вернуть JWT-токен.

## 4. Создание JWT

При создании JWT необходимо указать:

- Issuer;
- Audience;
- срок действия токена;
- алгоритм подписи;
- секретный ключ.

Добавьте в JWT следующие Claims:

```
Name
Role
```

Например:

```
Name = student
Role = User
```

Установите ограниченный срок действия JWT.

## 5. Настройка JWT-аутентификации

Подключите:

```
Microsoft.AspNetCore.Authentication.JwtBearer
```

Настройте JWT-аутентификацию в Program.cs.

Сервер должен проверять:

- подпись токена;
- Issuer;
- Audience;
- срок действия токена.

Не забудьте подключить middleware для аутентификации и авторизации.

## 6. Защита методов API

Используйте:

```
[Authorize]
```

Настройте API следующим образом:

```
GET /api/tasks          - доступ без авторизации
GET /api/tasks/{id}     - доступ без авторизации
POST /api/tasks         - только с JWT
DELETE /api/tasks/{id}  - только с JWT
```

Таким образом, просматривать задачи смогут все клиенты, а изменять данные - только аутентифицированные пользователи.

## 7. Работа с Claims

В одном из защищённых методов получите информацию о пользователе из JWT.

Используйте:

```
HttpContext.User.Claims
```

Получите Claim Name и верните имя пользователя вместе с результатом выполнения операции.

## 8. Вызов защищённого API

Получите JWT через:

```
POST /api/auth/login
```

После этого передайте полученный токен в заголовке HTTP-запроса:

```
Authorization: Bearer <token>
```

Выполните запрос к защищённому методу API.

## 9. Проверка безопасности

Самостоятельно проведите следующие тесты:

| № | Проверка | Ожидаемый результат |
| --- | --- | --- |
| 1 | GET без токена | 200 OK |
| 2 | POST без токена | 401 Unauthorized |
| 3 | POST с корректным JWT | Успешное выполнение |
| 4 | DELETE с корректным JWT | Успешное выполнение |
| 5 | Запрос с изменённым JWT | 401 Unauthorized |
| 6 | Запрос с истёкшим JWT | 401 Unauthorized |
