**Модуль 06**

Тема: Защита доступа к API

## Цель работы

Научиться защищать методы ASP.NET Core Web API, используя API Key и JWT-аутентификацию, а также передавать данные авторизации через HTTP-заголовки.

## Задание 1. Создание Web API

Создайте проект ASP.NET Core Web API.

Создайте модель Product:

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
}
```

Создайте ProductController и реализуйте метод:

```
GET /api/product
```

Метод должен возвращать список из нескольких товаров.

Проверьте работу API через Swagger.

## Задание 2. Защита API с помощью API Key

Добавьте проверку API-ключа для доступа к API.

Клиент должен передавать ключ через HTTP-заголовок:

```
X-Api-Key: SecretKey123
```

Если ключ отсутствует или указан неправильно, API должен возвращать:

```
401 Unauthorized
```

Если ключ правильный:

```
200 OK
```

Проверьте оба сценария.

## Задание 3. Настройка JWT

Установите необходимый пакет:

```
Microsoft.AspNetCore.Authentication.JwtBearer
```

В Program.cs настройте JWT-аутентификацию.

Укажите:

- Issuer;
- Audience;
- IssuerSigningKey;
- проверку срока действия токена;
- ClockSkew.

Добавьте в конвейер приложения аутентификацию и авторизацию.

## Задание 4. Создание JWT-токена

Создайте AuthController.

Реализуйте метод:

```
POST /api/auth/login
```

Метод должен принимать:

```json
{
    "username": "student",
    "password": "12345"
}
```

Если данные правильные - сформируйте JWT-токен и верните его клиенту.

Установите срок действия токена.

## Задание 5. Защита метода

Добавьте атрибут:

```
[Authorize]
```

к одному из методов ProductController.

Попробуйте вызвать его без JWT.

Зафиксируйте полученный HTTP-код.

После этого получите токен через `/api/auth/login` и повторите запрос.

## Задание 6. Передача Bearer Token

Передайте полученный JWT через HTTP-заголовок:

```
Authorization: Bearer <token>
```

Убедитесь, что после успешной проверки токена сервер предоставляет доступ к защищённому ресурсу.

## Задание 7. Проверка безопасности

Проверьте четыре ситуации:

1. Запрос без токена.
2. Запрос с корректным JWT.
3. Запрос с изменённым JWT.
4. Запрос с истёкшим JWT.

Для каждого случая запишите полученный HTTP Status Code.
